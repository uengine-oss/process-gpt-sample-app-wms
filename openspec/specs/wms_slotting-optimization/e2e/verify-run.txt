D. SYNTHETIC CONSUMPTION — standing in for a feature that does
   not exist yet
==============================================================

-- The rows below are inserted DIRECTLY, as superuser, bypassing every
-- RPC. No code path in this repository produces them (see §C1/§C2).
-- They simulate what a future outbound-fulfilment RPC would write, and
-- they exist for exactly one reason: without them the ABC arithmetic
-- can never be exercised. source_type is tagged SLOT-V-synthetic-
-- consumption so they are trivially identifiable and are deleted in §L.

-- Quantities are chosen so the cumulative share lands EXACTLY on both
-- cutoffs — the boundary is the interesting case (migration V5):
--   P1  60  -> cum  60 =  60%  -> A
--   P4  20  -> cum  80 =  80%  -> A   <- exactly 80, inclusive
--   P2  15  -> cum  95 =  95%  -> B   <- exactly 95, inclusive
--   P3   5  -> cum 100 = 100%  -> C
